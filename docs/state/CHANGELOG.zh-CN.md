## [1.2.6] - 2026-06-01

### 修复
- 通过排除仅词形变化的形式（如 `-ing`、`-ed` 以及复数变体）同时保留易混淆的近音、近形选项，让听力选择题的干扰项真正具有迷惑性。

- 将本地内部服务调用与全局代理设置隔离，确保就绪检查与 AI 执行客户端始终走本地运行时路径。
- 收紧了考试工作区、选项查找 CSS 变量、受管音频错误处理、游戏单词载荷以及遗留存储迁移测试的前端 TypeScript 边界。

### 运营
- 将发布收尾与已部署的 feature-wish 工单绑定，以便在生产部署后可对已交付的请求进行一致的标记。

### 验证
- 在发布前对听力选择、单词音频回退、feature-wish 工作流、前端类型检查、前端构建、仓库守卫以及发布风险测试覆盖进行了验证。

## [1.2.4] - 2026-05-23

- 通过限制练习结果发件箱，并使 smart-mode 与 quick-memory 的本地写入在配额内安全，从而让 Ebbinghaus 复习答案在浏览器存储压力下仍可持续流转。

- 在生产风格的学习状态修复中，保留了作用域内的 quick-memory 与错词完成状态。

### 运营
- 在生产环境发布并验证了存储压力热修复，包括拆分服务 schema 迁移、切换后冒烟以及学习核心日志检查。
- 从发布路径修复了生产 Wave 5 投影漂移，并成功完成发布收尾。

### 验证
- 验证了聚焦的后端 schema、幂等性、投影与发布收尾测试；前端的练习结果、smart-mode 与 quick-memory 配额测试；前端 lint；文件行守卫；以及生产冒烟/收尾。

## [1.2.1] - 2026-05-07

### 亮点
- 交付了 `v1.1.1` 之后的生产线，稳定了拆分后端运行时、OSS 托管的前端资源、练习结果摄入以及基础的词汇学习闭环。
- 保留基础练习、Ebbinghaus 复习、错词恢复与学习者统计在直接学习路径上，同时将五维游戏与 AI 口语作为独立的进阶模式族。
- 新增了首个移动端工作区脚手架与共享的 app-core 包，为未来的原生客户端工作打好基础。

### 学习与练习
- 新增幂等的练习结果命令/发件箱流程，使练习尝试携带稳定元数据，可在不重复计数的条件下重试。
- 从基础练习模式记录 Ebbinghaus 复习活动，包括 quick-memory 复习流程与到期复习动作。
- 稳定了 quick-memory 复习、重启、恢复、队列分页、冷路径查询、音频播放与本地重试行为。
- 在错词、章节与 quick-memory 练习流程中保留复习词序与作用域内的恢复快照。
- 新增章节组续作控件以及章节与错词练习的复习限额感知分组。
- 改进跟读模式，新增发音评分、声学回退、片段音频支持、分段细化以及生产样式修复。
- 统一了练习音频播放，使普通单词音频保持在标准轨道上。

### 词表、书籍与单词详情
- 新增受保护的自定义书导出与同步流程用于错词，包括排序词序、过滤选择操作、追加/更新支持以及网关超时修复。
- 在常规书单中隐藏遗留的错词系统书，并在词表读取中对错词计数进行去重。
- 新增高级单词助记词表、LLM 与 Qwen 快照数据、注富化工具以及高级记忆注释的回归覆盖。
- 新增单词详情注富化、选项查找、方向键导航、易混淆词查找加固以及网关中直接单词音频 GET 支持。
- 修正了音标音频条目，并使收藏单词音频使用音标覆盖数据。

### AI、笔记与学习者画像
- 新增 AI 聊天 Markdown 渲染以及配套的 Markdown 样式。
- 新增前端错误日志收集与后端摄入，以便更好地进行生产诊断。
- 新增 feature-wish 相关接口与画像弹窗支持。
- 新增 AI 首页 todos、学习日一致性修复、学习者画像推荐对齐以及会话重叠防护。
- 加固了 AI/自定义书 schema 回退，并新增跟读评估回退覆盖。

### 游戏与 UI
- 上线了主题化的五维游戏路由族、关卡状态、任务 UI、地图路线拆分、HUD 状态、生成的 UI 资源以及文本安全的游戏模板。
- 将游戏与前端 UI 资源迁移到 OSS 托管分发，包括 gzip/公共头处理与 SPA 目录回退修复。
- 美化了学习中心卡片、词汇测试布局、跟读练习布局、错词页面、全局单词搜索、设置、移动端 admin 用户表以及生产游戏地图控件。
- 新增本地 web-vitals 上报并稳定了游戏主题冷启动。

### 后端与运行时
- 推进了拆分服务运行时，包括 macOS 本地启动、分组领域工作器、低内存整合运行时、瘦身服务壳、就绪探针以及环境加载修复。
- 新增学习活动真实合计、回填工具、每日账本防护、切换支持以及统一的练习尝试事实。
- 为学习核心练习写入新增死锁重试处理，并避免请求时的主控表检查。
- 加固了词表 schema 边界、拆分投影验证、admin 投影冒烟检查以及发布风险测试门禁。
- 为自定义书排序、feature wishes、练习结果、学习合计及相关服务自有模型新增了服务 schema 迁移。

### 发布与运营
- 将生产发布流程转向基于预构建工件的单次发布、工作器感知的服务重启、发布健康看门狗以及更安全的回滚行为。
- 新增从发布工件进行 OSS 前端资源发布、资源基础校验以及存储分发加固。
- 新增 broker/运行时验证、生产预检、部署冒烟检查以及 CI 发布工件流式传输修复。
- 新增发布收尾/存储演练加固以及生产部署风险用户旅程覆盖。
- 移除了遗留的 Windows 启动脚本，并记录了仅限 Mac 的本地运行时基线。

### 移动端
- 新增 `apps/mobile` React Native 脚手架，包含 Android/iOS 工程文件、会话上下文、存储、基础页面、导航、API 接入以及原生音频采集桥接占位。
- 新增 `packages/app-core`，包含共享的 API、鉴权、语音会话、schema 与存储工具。

### 文档
- 新增练习模式数据流文档、练习结果链路重构规划、移动端原生 PRD、高级助记生成 PRD、五维游戏交付说明、发布提交日志以及本地 UI/API/浏览器测试报告。

### 验证
- 通过文件行守卫、前端仓库守卫、聚焦的前端单元测试、聚焦的后端 pytest 覆盖、生产预检以及切换后的生产冒烟对发布线进行了验证。
