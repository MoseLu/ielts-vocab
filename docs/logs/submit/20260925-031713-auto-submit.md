## Commit Body

PRD-07 phase 2 rotation fix: the nohup logs in
logs/runtime/app-services-mac/*.out.log / .err.log grew
unbounded because start-microservices.sh truncated the file at
each launch but never rotated the previous one. With
Promtail now tailing these files into Loki, a single 4 GB
log would slow the tail to a crawl on every Loki query.

Changes:
- start_logged_process() now checks both stdout and stderr
  files before truncation. If either exceeds 50 MB, the file
  is moved aside to <name>.YYYYMMDD-HHMMSS.rotated and gzipped
  on best-effort. Only one rotation per start; subsequent
  runs overwrite the rotated file until the next >50 MB breach.
