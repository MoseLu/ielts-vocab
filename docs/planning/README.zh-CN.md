# 规划文档

此目录用于存放产品规划与执行导向的计划文档。

## 子目录

- `implementation/`：具体工程计划，包含任务、推进顺序与验证步骤
- `implementation/templates/`：可复用的实施计划模板

## 当前文档

- [product-requirements-document.md](./product-requirements-document.md)：当前产品基线、目标、范围与成功标准
- [ui-redesign-plan.md](./ui-redesign-plan.md)：当前产品界面的分阶段 UI 优化计划
- [mobile-visual-resource-list.md](./mobile-visual-resource-list.md)：移动端手绘视觉资源清单，覆盖页面框架、卡片、控件、图标与反馈状态

## 规范

- 计划应具有时间边界且可执行。
- 产品基线文档应聚焦于用户问题、范围、用户旅程与成功指标。
- 持久化的技术原理应迁移至 `docs/architecture/specs/`。
- 当计划已完成且其成果对多个发布版本具有价值时，请在 `docs/milestone/` 中新增或更新里程碑。
- 新的工程推进计划应基于 `implementation/templates/implementation-plan-template.md` 模板开始。
